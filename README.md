## 🎯 Tentang Pendekin

**Pendekin** adalah platform URL Shortener modern yang dirancang untuk membantu pengguna membuat, mengelola, dan membagikan tautan dengan lebih mudah, cepat, dan profesional. Selain menghasilkan URL yang lebih singkat, Pendekin juga menyediakan analitik pengunjung, QR Code, fitur keamanan, serta dashboard administrasi dalam satu platform yang terintegrasi.

Dibangun menggunakan Laravel, React, TypeScript, dan Inertia.js, Pendekin mengutamakan performa, keamanan, serta pengalaman pengguna agar setiap proses pengelolaan tautan terasa sederhana namun tetap bertenaga.

## 🏗️ Architecture

Pendekin mengadopsi arsitektur full-stack modern dengan Laravel sebagai backend dan React sebagai frontend yang dihubungkan menggunakan Inertia.js. Pendekatan ini memberikan pengalaman Single Page Application (SPA) tanpa mengorbankan kemudahan pengembangan di sisi server.

```text
                Browser
                   │
        React + TypeScript
                   │
             Inertia.js
                   │
              Laravel 12
          ┌────────┴────────┐
          │                 │
       MySQL             Redis
```
